What this audit can and can’t measure

This report uses live Lighthouse data returned by Google PageSpeed Insights for the URL you enter. Scores and findings are based on that returned audit, not random preset numbers. A public scan cannot inspect private Shopify admin settings, confirm a payment provider is activated, or complete a real checkout. If Google's service does not return an audit, the app explains the issue rather than fabricating a score.
